## Change approval workflow

Before modifying, adding, or deleting any code or file:

1. Explain the proposed plan to the user first.
2. Wait for the user's explicit approval.
3. Only execute the approved changes after approval is given.

Read-only inspection is allowed before approval when it is needed to understand the task and prepare an accurate plan.
